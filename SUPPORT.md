# Support

OpenSend is pre-release open-source software and does not currently include paid or guaranteed
support.

- Setup and operations: read [README.md](README.md), [docs/SELF_HOSTING.md](docs/SELF_HOSTING.md)
  and [docs/OPERATIONS.md](docs/OPERATIONS.md).
- API behavior: read [docs/API.md](docs/API.md).
- Reproducible bugs: use the GitHub bug-report form after searching existing issues.
- Usage questions and deployment discussion: use GitHub Discussions.
- Feature proposals: use the feature-request form.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md); never use a public issue.

When asking for help, provide the OpenSend version/commit, installation method, operating system,
Node and Docker versions, sending provider, relevant configuration names (not values), concise
steps and redacted logs. Never publish secrets, cookies, message contents, recipient/customer data,
private infrastructure details or production database extracts.
